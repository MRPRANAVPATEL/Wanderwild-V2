# WANDERWILD V2 — Premium Travel Magazine Website Template

**Thoughtfully built by Pranav Patel.**

A visually immersive, responsive **travel journal and editorial magazine website template** created with HTML, CSS, and vanilla JavaScript. WANDERWILD V2 explores bold typography, vivid color, travel photography, interactive storytelling, and a magazine-inspired browsing experience.

**[Explore the live website](https://mrpranavpatel.github.io/Wanderwild-V2/)** · **[Browse the source code](https://github.com/MRPRANAVPATEL/Wanderwild-V2)**

> **Personal project and frontend practice.** This template was built for learning, design experimentation, and portfolio presentation. It is a demonstration website, not a live travel agency, publishing service, or subscription product. Use or adapt it at your own discretion and check applicable image/font licenses before commercial use.

## About the project

WANDERWILD V2 is the second design exploration of **[Wanderwild](https://github.com/MRPRANAVPATEL/Wanderwild)**. It takes the independent travel-magazine concept further with a playful editorial direction, expressive page transitions, creative compositions, and interactive tools for browsing places and stories.

It is a suitable starting point for a:

- Travel blog or independent travel journal
- Digital travel and lifestyle magazine
- Destination storytelling website
- Adventure photography portfolio
- Editorial travel-brand landing page

## Features

- **Immersive editorial hero:** Layered destination photography, animated lettering, coordinates, and travel-inspired visuals.
- **Destination discovery:** Explore featured places and narrow the selection with category filters.
- **Travel stories:** Editorial cards and story filtering for different interests.
- **Interactive search:** Search the destination and story content already included in the page.
- **Photography experience:** Image galleries and a lightbox-style photo viewer.
- **Map-inspired exploration:** A designed travel-map section with interactive visual elements.
- **Browse by mood:** Travel inspiration presented through different moods and photographic treatments.
- **Featured journal content:** Magazine-like storytelling and a cover-story presentation.
- **Newsletter interface:** A boarding-pass-inspired email form with client-side feedback.
- **Responsive navigation:** Desktop navigation, a fullscreen menu, and in-page section links.
- **Polished interactions:** Loading sequence, scroll reveals, cursor effects, thematic color changes, and motion-aware behavior.

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/MRPRANAVPATEL/Wanderwild-V2.git
   ```
2. Open the project folder:
   ```bash
   cd Wanderwild-V2
   ```
3. Open `index.html` in your browser. For a more convenient development experience, serve the folder using **VS Code Live Server** or a local static web server.

The project uses relative paths for `css/style.css` and `js/script.js`, so it is suitable for deployment from a repository subpath.

## Deploying

### GitHub Pages

The website is **already published** at:

https://mrpranavpatel.github.io/Wanderwild-V2/

The root `index.html` is the entry point. To review publication settings, open the GitHub repository and go to **Settings → Pages**.

### Vercel (optional)

Import this GitHub repository into Vercel and deploy it as a static site with no framework or build command. Add the Vercel production URL to this README after deployment.

## Demo limitations and third-party assets

- Some editorial destinations, story links and social links are **demonstration placeholders**, not published articles or connected social accounts.
- Search and category filters act on content present in the frontend; there is no CMS or search server.
- The newsletter has a frontend UI and confirmation flow. **It is not connected to an email marketing service**, and a success message should not be treated as a real subscription.
- No user accounts, backend API, payments, or production content-management workflow are included.
- Fonts and images are loaded from external services and require an internet connection. Verify image usage rights and third-party terms before reuse.
